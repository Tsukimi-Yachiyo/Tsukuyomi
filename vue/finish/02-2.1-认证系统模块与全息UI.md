## 问题解决方案

### 1. 响应拦截器兼容多种返回类型

**问题**：后端返回的 code 可能是字符串或数字
**解决**：在响应拦截器中同时判断 `code === 200 || code === 0 || String(code) === '200'

### 2. 登录响应可能直接返回 token 字符串

**问题**：部分接口直接返回 token 字符串而非对象
**解决**：在 store 中判断响应类型，兼容两种情况
