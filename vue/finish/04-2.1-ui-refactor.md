## 实现要点

### 1. Composables 层

**useAuth.ts**: 封装所有认证相关逻辑
- 认证状态管理（loading、errorMsg、successMsg）
- 认证模式切换（login/register/change/mail）
- 登录/注册/修改密码/发送验证码方法
- 错误和成功消息处理

**useClock.ts**: 时钟管理
- 实时时间更新
- 日期/时间格式化方法

**useCountdown.ts**: 倒计时管理
- 可配置倒计时时长
- 开始/停止方法
- 自动清理

### 2. 新 UI 布局

**左侧**: 功能切换区
- 新用户注册按钮
- 重置密码按钮
- 当前选中状态高亮

**右侧**: 表单区
- 根据模式动态显示对应输入框
- 登录模式：用户名 + 密码
- 注册模式：用户名 + 邮箱 + 验证码 + 密码 + 确认密码
- 修改密码模式：用户名 + 邮箱 + 验证码 + 新密码

### 3. 图形验证码

- Canvas 绘制验证码
- 随机颜色（青色/粉色/绿色）
- 干扰线和干扰点
- 点击刷新
- 验证成功回调
- 验证失败自动刷新

### 4. SVG 图标

- 从素材目录移动到 assets/icons
- 修改颜色为青色 (#4df0ff)
- 在头部右侧显示 64x64 大小

### 5. 文案优化

- "系统接入认证" → "密码登录"
- "TSUKUYOMI COAST SYSTEM" → "月读空间"
- 去掉生硬的英文说明
- 使用更友好的中文标签

### 6. 尺寸优化

- 从 max-w-3xl 改为 max-w-2xl
- 更紧凑的布局
- 更适合屏幕空间
