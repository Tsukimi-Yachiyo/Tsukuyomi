# 05-2.1-layout-adjust: 登录界面布局调整

**完成时间**: 2026-05-11

## 关键变更

### 1. 布局调整

- **左侧**: 改为动态闪烁棋盘（4x4）
- **右侧**: 登录表单，按钮移到登录按钮上方
- **按钮样式**: 改为无边框文本链接

### 2. 新增组件

`DynamicChessboard.vue`: 动态闪烁棋盘组件
- 4x4 网格布局
- 从左下角第一个格子开始（索引 12）
- 逐行向上闪烁（左下 → 左上 → 中下 → 中上 → ...）
- 每 300ms 切换一个格子的亮/暗状态
- 平滑的 500ms 过渡动画
- 青色发光效果（`shadow-[0_0_10px_rgba(77,240,255,0.8)]`）

### 3. 按钮样式

- 无边框设计
- 鼠标悬停时显示下划线
- "还没有账号？注册"：青色
- "忘记密码？"：粉色
- "返回登录"：青色（非登录模式时显示）

### 4. 文件结构

```
src/
└── components/
    ├── Login.vue                 # 重构后的登录主组件
    └── login/
        └── DynamicChessboard.vue  # 新增：动态闪烁棋盘
```

## 实现细节

### 棋盘动画逻辑

```typescript
// 从左下角（索引12）开始，逐行往上
// 顺序：12 → 13 → 14 → 15 → 8 → 9 → 10 → 11 → 4 → 5 → 6 → 7 → 0 → 1 → 2 → 3
const row = 3 - Math.floor(currentStep / 4);
const col = currentStep % 4;
const index = row * 4 + col;

// 切换当前格子（亮 ↔ 暗）
cellStates.value[index] = !cellStates.value[index];
```

### 按钮显示逻辑

- **登录模式**: 显示"注册" + "忘记密码"
- **其他模式**: 显示"返回登录"
