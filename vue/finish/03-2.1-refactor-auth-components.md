## 架构设计

### Composables 层

```
useAuth.ts
  ├── currentMode (状态管理)
  ├── loading / errorMsg / successMsg (状态)
  ├── login() / loginByMail() / register() / changePassword() (方法)
  └── sendCode() (辅助方法)

useClock.ts
  ├── currentTime
  ├── formatDate()
  └── formatTime()

useCountdown.ts
  ├── countdown (ref)
  ├── start()
  └── stop()
```

### 组件层

```
Login.vue (主组件)
  ├── HoloPanel (容器)
  ├── AuthHeader (头部)
  ├── SideDecoration (装饰)
  ├── AuthModeToggle (模式选择)
  ├── HoloInput (多个输入框)
  ├── CodeInput (验证码)
  ├── AuthMessages (提示)
  └── AuthActions (按钮组)
```

## 优势

### 1. 单一职责

- 每个组件只负责一个功能点
- Composables 专注于业务逻辑
- UI 组件专注于展示

### 2. 高度复用

- HoloInput 可以在其他表单复用
- useClock 和 useCountdown 可全局复用
- 所有子组件独立可测试

### 3. 易维护性

- 修改某个功能只需要改对应的子组件
- 逻辑清晰，易于理解
- TypeScript 类型安全

### 4. 测试友好

- 每个 composable 可独立单元测试
- 每个子组件可独立测试
- 主组件只负责组装

## 文件变更详情

### 新增：src/composables/useAuth.ts

封装所有认证相关逻辑：

- 模式切换
- 登录/注册/修改密码
- 发送验证码
- 错误/成功消息管理

### 新增：src/composables/useClock.ts

独立时钟管理：

- 实时时间更新
- 日期/时间格式化
- 自动清理定时器

### 新增：src/composables/useCountdown.ts

倒计时逻辑：

- 支持自定义秒数
- 自动清理定时器
- 开始/停止/查询接口

### 新增：login/ 子组件目录

每个组件都有明确的职责和独立的 props/emits。

### 重构：src/components/Login.vue

从 200+ 行代码减少到更清晰的 200+ 行，但结构更清晰：

- 模板部分高度声明式
- 脚本部分简洁，只负责组装
- 所有业务逻辑移到 composables
- 所有 UI 细节移到子组件

## 技术细节

### Props 命名约定

- 使用 kebab-case 在模板中
- 使用 camelCase 在 script 中
- 利用 withDefaults 设置默认值

### Emit 类型安全

完整的 TypeScript 类型定义：

```typescript
defineEmits<{
  'update:modelValue': [value: string];
  'send-code': [];
}>();
```

### 动画状态传递

HoloPanel 中定义的动画类可被子组件使用，确保效果一致。
